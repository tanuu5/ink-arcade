# INK ARCADE

狙って撃つだけ。ブラウザでそのまま遊べる、インク系シューティング2本立てです。

**▶ 遊ぶ: https://tanuu5.github.io/ink-arcade/**

## INK RAIL

レールの上を自動で進む3Dレールシューター（強制スクロール）です。

- 照準を合わせるだけで、BGMの16分音符に合わせて弾が出ます（オート射撃。メニューで手動にも変えられます）
- 的の真ん中に当てると PERFECT。コンボが続くと倍率と音階が上がります
- ボムは近づかれる前に撃つ。ニコちゃんは撃たないように照準を外す
- 終盤にボス「BIG TARGET」が登場。倒してゴールすると花火と紙吹雪で祝われます
- 難易度は EASY / NORMAL / HARD / INSANE の4段階。速度、的の数、BPM が変わります
- 難易度ごとのハイスコアはブラウザに保存されます

| 操作 | |
|---|---|
| 照準 | マウス／タッチ |
| 発射（手動モード） | クリック（押しっぱなしで連射）／スペース |
| 一時停止 | Esc / P |

## INK DASH

キャラは勝手に走り回り、プレイヤーは狙って撃つだけのインク塗り合いゲームです。90秒で多く塗ったチームの勝ちです。

## 技術メモ

- 各ゲームは1つのHTMLファイルで完結しています（ビルド不要）
- 3D描画は [Three.js](https://threejs.org/)（r170、CDNから読み込み）
- BGMと効果音は Web Audio API でその場で合成しています（音声ファイルなし）
- テクスチャは Canvas で描いています（画像ファイルなし）

ローカルで動かす場合は、ES Modules を使うため簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8765
```

http://localhost:8765/ を開きます。
